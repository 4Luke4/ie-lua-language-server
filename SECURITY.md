# Security Policy

## Supported Versions

Only the latest released version is supported with security updates.

## Reporting a Vulnerability

Report suspected vulnerabilities privately through the project maintainers. Do not disclose security issues in public issues or merge requests until a fix is available.

Include:

- Affected version.
- Reproduction steps.
- Impact assessment.
- Any relevant logs or sample files.

## Handling

Maintainers triage reports, confirm impact, prepare a fix, and publish a security release when warranted.
